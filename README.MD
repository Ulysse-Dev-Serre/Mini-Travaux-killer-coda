Afin de rendre le devoir facilement lisible, nous avons séparé chaque semaine dans un dossier distinct.
Dans chaque dossier, on retrouve les fichiers de code, les captures d’écran d’exécution et un fichier Markdown qui contient les commandes d’exécution.
Pour les projets des semaines 7 à 10, nous avons conservé uniquement les fichiers importants, comme le dossier lib, afin d’alléger l’ensemble du répertoire.

Dans le fichier Setting.md, nous avons rédigé un guide pour l’installation locale de Dart via les lignes de commande avec Chocolatey, pour les utilisateurs de OS Windows
