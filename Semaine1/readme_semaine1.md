## Partie 1 : Variables et Types de Données

### Exercice 1 : variables.dart
Création de variables de différents types (int, String, double, bool) et affichage avec interpolation.
```bash
dart variables.dart
```

### Exercice 2 : modification.dart
Modification de valeurs de variables existantes (sans redéclarer avec `var`).
```bash
dart modification.dart
```

### Exercice 3 : calculs.dart
Calculs mathématiques avec des variables (aire et périmètre d'un rectangle).
```bash
dart calculs.dart
```

### Exercice 4 : moi.dart
Personnalisation d'un programme avec vos propres informations.
```bash
dart moi.dart
```

## Partie 2 : Fonctions en Dart

### Exercice 1 : premiere_fonction.dart
Fonction simple sans paramètres ni retour (`void`). Réutilisation du code.
```bash
dart premiere_fonction.dart
```

### Exercice 2 : avec_parametres.dart
Fonctions avec un ou plusieurs paramètres. Comprendre l'ordre des arguments.
```bash
dart avec_parametres.dart
```

### Exercice 3 : calculatrice.dart
Fonctions mathématiques avec retour de valeur (`int`). Composition de fonctions.
```bash
dart calculatrice.dart
```

### Exercice 4 : temperature.dart
Convertisseur Celsius ↔ Fahrenheit avec type `double`. Calculs scientifiques.
```bash
dart temperature.dart
```

### Exercice Bonus : validateur.dart
Validateur d'âge avec retour `bool` et conditions `if/else`.
```bash
dart validateur.dart
```
